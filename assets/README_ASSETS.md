## Catatan Editing

- Semua screenshot publik harus memakai data dummy.
- Brand ideal di screenshot: `MedPraktik`.
- Hindari nama pasien, nomor telepon, alamat, NIK, atau data medis nyata.
- Untuk website, versi `.webp` boleh dibuat dari file PNG agar lebih ringan.
- Pertahankan rasio screenshot sekitar `1.84:1` agar UI tidak terpotong.
