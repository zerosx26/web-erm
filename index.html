Workflow produk

Dari pasien datang sampai backup data, alurnya dibuat dekat dengan praktik harian.

  1. 1

    Pasien datang dan registrasi

    Admin mencari pasien lama atau menambahkan pasien baru, lalu membuat kunjungan hari ini.

  2. 2

    Masuk antrean

    Pilot/Basic dimulai dari registrasi pasien dan kunjungan. Antrean sederhana diposisikan sebagai opsi Basic Plus setelah validasi fitur.

  3. 3

    Dokter isi SOAP

    Dokter mencatat keluhan, pemeriksaan, assessment, plan, diagnosis, resep, dan dokumen klinis.

  4. 4

    Cetak resep, surat, invoice

    Resep, surat, dan laporan klinis tersedia di Pilot/Basic. Invoice dan kwitansi masuk Basic Plus bila fitur sudah siap untuk pengguna tersebut.

  5. 5

    Backup dan audit

    Owner dapat menjaga data lokal dengan backup/restore dan melihat aktivitas operasional penting.

Cara membeli

Pembelian dibuat sederhana, tetapi installer dan aktivasi tetap terkontrol.

Pembelian dibantu via WhatsApp agar paket, instalasi, pembayaran, dan aktivasi sesuai kebutuhan perangkat praktik. Tidak ada checkout online untuk tahap awal.

  1. 1Minta Demo

    Klik WhatsApp, jelaskan jenis praktik, jumlah perangkat, dan pencatatan saat ini.

  2. 2Pilih Paket

    Setelah demo 15 menit, paket disarankan sesuai kebutuhan Basic, Assisted Setup, atau Basic Plus terbatas.

  3. 3Bayar Transfer/QRIS

    Nominal dan rekening/QRIS dikirim via WhatsApp setelah paket disepakati, bukan dipasang terbuka di website.

  4. 4Terima Installer

    Installer privat, checksum SHA-256, dan panduan instalasi dikirim setelah pembayaran tervalidasi.

  5. 5Aktivasi Perangkat

    Aplikasi aktif memakai license key berbasis device fingerprint sesuai paket dan jumlah perangkat.

Anti-pembajakan: Installer saja tidak cukup untuk memakai aplikasi penuh. Aktivasi lisensi dilakukan per perangkat, dan pindah laptop diproses manual lewat WhatsApp.

FAQ

Pertanyaan sebelum konsultasi atau demo.

Apakah perlu internet?

Tidak wajib untuk operasional harian. Produk diposisikan offline-first untuk Windows.

Data disimpan di mana?

Data tersimpan lokal di laptop atau server praktik, sesuai paket dan setup yang digunakan.

Bisa dipakai lebih dari satu laptop?

Paket Advance Local Network direncanakan untuk server lokal dan client admin/dokter melalui WiFi lokal.

Apa beda Pilot/Basic dan Basic Plus?

Pilot/Basic fokus RME klinis inti: pasien, kunjungan, SOAP, resep, surat, laporan, PDF/cetak, dan backup. Basic Plus menambahkan antrean/kasir sederhana jika fitur tersebut sudah cocok untuk skenario calon pengguna.

Apakah bisa cetak resep, surat, dan invoice?

Resep dan surat tersedia di Pilot/Basic. Invoice dan kwitansi masuk Basic Plus dan tidak dijanjikan untuk semua pilot awal.

Apakah bisa backup?

Ya, backup/restore lokal tersedia sebagai bagian penting dari produk offline.

Apakah sudah SATUSEHAT?

Belum diklaim siap. SATUSEHAT masuk roadmap Pro/lanjutan setelah produk offline stabil.

Bagaimana jika laptop rusak?

Data dapat dipulihkan dari backup yang valid. Praktik tetap perlu disiplin melakukan backup berkala.

Bagaimana proses instalasi dan aktivasi?

Aplikasi diinstal di Windows, lalu license key dibuat berdasarkan device fingerprint perangkat pembeli.

Bagaimana proses pembelian dan pembayaran?

Setelah demo dan paket cocok, pembayaran dilakukan manual via transfer bank atau QRIS. Nominal dan instruksi pembayaran dikirim via WhatsApp agar tidak ada salah paket atau salah transfer.

Apakah installer bisa didownload bebas?

Tidak untuk tahap awal. Installer dikirim setelah pembayaran tervalidasi, bersama checksum SHA-256, panduan instalasi, dan instruksi aktivasi.

Bagaimana mencegah aplikasi dibajak?

Installer tidak mengaktifkan aplikasi penuh tanpa license key. Lisensi dikunci ke device fingerprint perangkat sesuai paket dan jumlah perangkat.

Bagaimana proses demo?

Demo awal diarahkan 15 menit lewat WhatsApp atau remote singkat untuk melihat jenis praktik, jumlah perangkat, dan paket yang paling masuk akal.

Apakah bisa langsung bayar online?

Belum. Tahap awal memakai konsultasi/demo manual agar kebutuhan praktik dipahami sebelum instalasi dan aktivasi.
