# Template Pengiriman Installer

## Pesan Pengiriman

Berikut installer ERM Offline, Dok:

- Paket:
- Versi installer:
- Link installer privat:
- SHA-256:

Nama file disarankan:

`ERM-Offline-[Paket]-v[versi]-Setup.zip`

Mohon install di laptop Windows yang akan dipakai untuk praktik. Setelah aplikasi dibuka, kirim device fingerprint/request code yang muncul agar license key bisa dibuat untuk perangkat tersebut.

## Instruksi Singkat

1. Download installer dari link privat.
2. Pastikan nama file dan checksum SHA-256 sesuai.
3. Extract/install aplikasi.
4. Buka aplikasi.
5. Kirim device fingerprint/request code ke WhatsApp.
6. Masukkan license key yang dikirim setelah aktivasi dibuat.
7. Lakukan simulasi dengan data dummy sebelum memakai data pasien asli.

## Catatan Lisensi

- Lisensi dikunci ke perangkat sesuai paket.
- Installer boleh disimpan sebagai arsip, tetapi aplikasi penuh tidak aktif tanpa license key valid.
- Jika laptop rusak atau pindah perangkat, hubungi WhatsApp untuk proses aktivasi ulang manual.
