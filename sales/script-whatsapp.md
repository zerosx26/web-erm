## Setelah Pembayaran Tervalidasi

Pembayaran sudah saya terima, Dok. Langkah berikutnya:

1. Saya kirim link installer privat.
2. Saya kirim checksum SHA-256 untuk verifikasi file.
3. Dokter install aplikasi di laptop Windows.
4. Aplikasi menampilkan device fingerprint/request code.
5. Saya bantu buatkan license key untuk perangkat tersebut.

Installer boleh disimpan untuk arsip, tetapi aplikasi penuh hanya aktif dengan license key perangkat yang valid.

## Jika Pindah Laptop

Bisa dibantu manual, Dok. Nanti perangkat lama dicatat sebagai nonaktif/pindah, lalu perangkat baru perlu mengirim device fingerprint/request code baru untuk aktivasi ulang sesuai ketentuan paket.
